# Clavier Zarma Officiel — Android & Windows (Écriture ELDAS)

Clavier virtuel libre et gratuit pour écrire nativement la langue **Zarma** avec ses caractères propres (sans forme latine), basé sur le système de l'académie **ELDAS**.

## Téléchargement Gratuit
Rendez-vous dans l'onglet **[Releases](../../releases)** à droite pour télécharger :
1. **`ZarmaKeyboard-Android.apk`** (Android avec changement de couleurs intégré)
2. **`ZarmaKeyboard-Windows.zip`** (Windows 10/11 + police `ZarmaEldas.ttf`)
3. **`ZarmaScript-SVG-Pack.zip`** (Les 69 glyphes vectoriels `.svg` + `.ttf`)
